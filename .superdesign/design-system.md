# MMD LAB design system

MMD LAB is a local, keyboard-friendly realtime 3D workstation for creators. Keep the WebGL viewport visually dominant. Use a deep slate workspace with a cool blue accent, clear density hierarchy, compact controls, and Japanese labels. The desktop shell has a top command bar, a resizable-feeling asset rail, and an inspector rail. Mobile exposes each rail as an accessible modal drawer. Controls must be accessible by keyboard and express state using Headless UI data attributes. Avoid ornamental gradients, marketing patterns, and generic dashboard cards.

Core tokens: Inter / Noto Sans JP; dark background #0b1220; raised surfaces #111b2e; border #26334a; primary text #edf3ff; muted text #93a4be; accent #5b9dff; success #54d69b; danger #ff6b7a; 8px spacing grid; 10px radius; subtle shadow only for floating drawers.
